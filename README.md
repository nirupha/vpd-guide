# ВПД шаг за шагом

Интерактивный учебник по лабораторным работам ВПД (введение в профессиональную деятельность).
Сейчас в нём ЛР1 «Языки программирования, терминал и Git», следующие лабы добавятся позже.

Открыть: https://nirupha.github.io/vpd-guide/

- При первом запуске введи свои ФИО, группу и номер: примеры, `student_id`, `control_value` и язык feature-ветки пересчитаются под твой вариант.
- Нейронка подключается в «Настройках»: через любой чат (ChatGPT, Claude, DeepSeek, Gemini, Алиса, GigaChat, в том числе бесплатные) или по API-ключу (бесплатно: Google Gemini, OpenRouter, Groq).
- Всё хранится только в браузере. Прогресс переносится между устройствами через файл в «Настройках».
- Можно скачать `index.html` и открывать без интернета.
